# UI Design System

## Core Direction

- Minimalist, строгий, современный B2B.
- Интерфейсы должны выглядеть дорого, чисто и профессионально.
- Визуальный ориентир: Linear, Stripe, Notion.
- Типографика важнее декоративных элементов.
- Интерфейс строится вокруг текста и смысла, а не визуального шума.

## Color Rules

- Background: `#FFFFFF`.
- Primary text: black or dark gray.
- Secondary text: gray.
- Use one restrained accent color only, for example blue or violet.
- Do not use many colors.

## Typography Rules

- Large headings: around `38px` by default unless a section clearly needs larger emphasis.
- Subheadings: `28px` to `36px`.
- Body text: `16px` to `18px`.
- Use a modern font such as `Inter`, `Geist`, or a close equivalent.
- Text is the primary visual element.

## Layout Rules

- Maximum simplicity and cleanliness.
- Full-width sections by default with `20px` horizontal padding.
- Large spacing between sections: `80px` to `120px`.
- Clear vertical structure.
- A lot of whitespace.

## Component Rules

- Do not use icon cards.
- Do not use generic SaaS blocks.
- Do not use illustrations or emoji.
- Avoid decorative elements without function.

## Explicit Bans

- No shadcn-style UI.
- No generic SaaS layouts.
- No overloaded gradients.
- No playful or cartoonish design.

## UI Principles

- Each block should communicate one clear idea.
- Minimum elements, maximum meaning.
- No visual clutter.

## Tone

- Simple.
- Direct.
- No marketing fluff.
- Emphasis on outcome and business value.

## Working Rule

- Follow this design system by default for every new interface in this workspace.
- Update this file when the user changes the system.
